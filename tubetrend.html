📌 서비스 소개 (About)

TUBETREND는 전 세계 다양한 국가의 YouTube 실시간 인기 트렌드를 분석하고, 카테고리별로 떠오르는 콘텐츠 주제를 빠르게 탐색할 수 있도록 돕는 글로벌 인텔리전스 네비게이터입니다.

크리에이터, 마케터, 트렌드 분석가들이 어떤 키워드가 현재 전 세계적으로 주목받고 있는지 한눈에 파악할 수 있도록 직관적인 인터페이스와 심층적인 검색 기능을 제공합니다. 왼쪽 카테고리를 선택하거나 직접 검색어를 입력하여 최신 글로벌 동향을 확인해 보세요.

🛡️ 개인정보처리방침 (Privacy Policy)

TUBETREND는 사용자의 개인정보를 소중하게 생각하며, 안전하게 보호하기 위해 최선을 다하고 있습니다.

1. 수집하는 정보: 본 서비스는 별도의 회원가입 없이 이용 가능하며, 서비스 제공을 위해 최소한의 비식별 정보(접속 국가, 언어 설정 등) 및 사용자가 입력한 검색어만을 일시적으로 처리합니다.
2. YouTube API 사용: 본 서비스는 YouTube Data API를 사용하여 공개된 트렌드 정보를 가져옵니다. 사용자가 개인 API 키를 입력할 경우, 해당 키는 브라우저의 로컬 스토리지(Local Storage)에만 안전하게 저장되며 서버로 전송되거나 수집되지 않습니다.
3. 쿠키(Cookies): 사용자 편의(다크모드 설정, API 키 저장 등)를 위해 브라우저 쿠키 또는 로컬 스토리지를 활용할 수 있습니다.
