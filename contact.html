자주 묻는 질문 (FAQ)

Q. TubeTrend는 무료인가요?

네, 기본 기능은 무료로 사용할 수 있습니다. Google 계정으로 로그인하시면 바로 이용 가능합니다.

Q. YouTube API 키가 필요한가요?

기본 기능은 별도의 API 키 없이 사용 가능합니다. AI 분석 기능 등 일부 고급 기능을 위해 Google Gemini API 키 설정이 필요할 수 있습니다.

Q. 어떤 브라우저를 지원하나요?

Chrome, Firefox, Safari, Edge 등 최신 웹 브라우저를 지원합니다. 최적의 경험을 위해 Chrome 브라우저 사용을 권장합니다.

Q. 데이터는 안전한가요?

네, TubeTrend는 이용자의 개인정보를 소중히 보호합니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

Q. 답변은 얼마나 걸리나요?

이메일 문의는 영업일 기준 1~2일 이내에 답변드리고 있습니다. 긴급한 사항은 제목에 [긴급]을 표기해 주세요.
